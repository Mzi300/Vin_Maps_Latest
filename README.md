# Project Overview

VinMaps is a full-stack navigation platform that combines modern web technologies with scalable backend architecture to provide intelligent mapping, business discovery, routing, and location-based services.

The project is designed to demonstrate modern software engineering principles including REST API design, modular architecture, secure authentication, database design, Docker containerization, and version control using Git and GitHub.

This project is currently under active development.

---

# Features

- Interactive map interface
- Business & Point of Interest search
- REST API architecture
- Secure authentication & authorization

# Architecture

VinMaps follows a modular architecture consisting of:

Frontend
- React
- TypeScript

Backend Services
- Authentication & User Management
- Business & Location Services
- Mapping & Navigation Services

Infrastructure
- PostgreSQL
- Redis
- Docker
- GitHub

Each backend service communicates through REST APIs, allowing the application to remain modular, scalable, and easier to maintain.

# Installation

Clone the repository

```bash
git clone https://github.com/Mzi300/Vin_Maps_Latest.git
```

Navigate into the project

```bash
cd Vin_Maps_Latest
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```
